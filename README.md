# Cadastro Interativo — Aula 12

Projeto da disciplina de Programação Web. A aplicação usa HTML, CSS e JavaScript puro para cadastrar pessoas e gerenciar os registros em uma tabela.

## Funcionalidades

- Cadastro de pessoas com nome e e-mail.
- Validação de campos obrigatórios e bloqueio de e-mails duplicados.
- Busca por nome ou e-mail em tempo real.
- Edição e exclusão de registros, com confirmação antes de excluir.
- Armazenamento dos cadastros no navegador com `localStorage`.

## Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` no navegador.
3. Preencha o formulário e clique em **Cadastrar**.

## Estrutura do projeto

| Arquivo | Responsabilidade |
| --- | --- |
| `index.html` | Formulário e tabela de cadastros |
| `style.css` | Estilos e adaptação para telas menores |
| `script.js` | Validação, busca, edição, exclusão e armazenamento |

## Conceitos praticados

Manipulação do DOM, eventos de formulário e de busca, uso de arrays para gerenciar registros e persistência de dados com `localStorage`.
